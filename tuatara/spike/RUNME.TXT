TUATARA TOOLCHAIN SPIKE - HOW TO RUN IT
=======================================

There are two folders, one per candidate toolchain:

  A-MSVC       built with Microsoft's compiler and linker
  B-CLANG      built with clang-cl and lld-link

Each holds the same three programs. They fit on one floppy per folder.

On each machine (NT 3.51, NT 4.0, Windows 2000), for each folder:

1. Copy the folder to a directory on the hard disk, for example C:\SPIKE\A.
   Running from a floppy works but is slow.

2. Open a command prompt in that directory and run:

     NTEXPORT

   It writes EXPORTS.TXT: the list of functions this Windows version has.
   It is the same for both folders, so you only need it once per machine.

3. Run:

     HELLO-NT

   A small window with a colour gradient appears for about two seconds.
   Results go to the screen and to HELLO-NT.TXT. The last line says how
   many checks passed and failed. Add /QUICK for a shorter SIMD test.

   If Windows says "The procedure entry point ... could not be located"
   or "is not a valid Windows NT application", write the message down
   exactly: that is the result for this toolchain on this system.

4. Copy back EXPORTS.TXT and both HELLO-NT.TXT files, renamed so we can
   tell them apart, for example:

     NT4-EXP.TXT   NT4-A.TXT   NT4-B.TXT

Also note each machine's CPU, RAM, number of CPUs, and whether WINSIMD
is installed.
