TUATARA TOOLCHAIN SPIKE - HOW TO RUN IT
=======================================

BUILD.TXT says which build this is. The first line HELLO-NT prints
says it too; please make sure they match the build you were sent.

There are three folders, one per build:

  A-MSVC       Microsoft compiler and linker, with YY-Thunks   (main candidate)
  B-CLANG      clang-cl and lld-link, with YY-Thunks
  C-NOYY       like A-MSVC but without YY-Thunks (a comparison)

Each holds the same programs. On each machine (NT 3.51, NT 4.0, Windows
2000), from a command prompt:

1. Once per machine, in A-MSVC:

     THRTEST

   It tries several ways of starting threads, each in its own process,
   and prints one line per experiment with an exit code. It writes
   THRTEST.TXT. This is the most useful result right now.

2. Once per machine:

     NTEXPORT

   It writes EXPORTS.TXT: the list of functions this Windows has.

3. In each folder, run:

     HELLO-NT

   Results go to the screen and to HELLO-NT.TXT. A window with a colour
   gradient appears for about two seconds near the end.

   - "RUN" lines show progress. If the program stops early, the last RUN
     line says where.
   - The last line, "worker-exit", gives the exit code even if the tests
     died. (NT 3.51's command prompt has no %ERRORLEVEL%, so this replaces
     ECHO %ERRORLEVEL%.)
   - A "CRASH" line, if any, gives the exception code, module and offset.
     Copy it exactly.
   - If Windows shows a dialog ("The procedure entry point ... could not be
     located", "is not a valid Windows NT application", "Application
     Error"), write the message down exactly.

4. If HELLO-NT stops at a test, run it again skipping that test, to see
   the rest:

     HELLO-NT /SKIP=threads

   Several tests can be listed: /SKIP=threads,dll   Or run just one:
   /ONLY=threads   Test names: os crt fpu threads dll files winsock simd
   misc gui thunks dlltls

5. Copy back THRTEST.TXT, EXPORTS.TXT and each folder's HELLO-NT.TXT
   (renamed, for example NT351-A.TXT, NT351-B.TXT, NT351-C.TXT), plus any
   dialog text. Photos of the screen are fine too.

Also note each machine's CPU, RAM, number of CPUs, and whether WINSIMD
is installed.
